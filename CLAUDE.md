# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This is the special GitHub **profile README** repository (`tnumajiri/tnumajiri`). Because the repo name matches the account name, GitHub renders its `README.md` at the top of the user's profile page at https://github.com/tnumajiri.

There is no application code, build system, test suite, or dependencies. The repository consists solely of `README.md`. Edits to that file change what visitors see on the GitHub profile.

## Working in this repo

- The only meaningful artifact is `README.md`. Preview changes by rendering the GitHub-flavored Markdown (e.g., in an editor preview) — there is nothing to build or run.
- Badges use [shields.io](https://shields.io) (`https://img.shields.io/badge/...` and `https://img.shields.io/github/...`).
- Stats cards use [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) hosted at `github-readme-stats.vercel.app`. The `username=tnumajiri` query parameter must stay in sync with the account.
- The profile links to X (Twitter) handle `@rimuruafi`. Keep the X badge and the inline link consistent if either is updated.

## Conventions

- Keep the README concise and section-based (`### About`, `### Stats`), matching the existing structure.
- Badges are grouped at the top, directly under the `# tnumajiri` heading.
- When changing the handle, username, or social links, update every occurrence (badge URL and Markdown link) so they remain consistent.
