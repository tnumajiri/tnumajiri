# キャベツ生育モデル比較 — 酷暑下での挙動

農研機構（NARO）系のキャベツ生育・収穫予測モデルを調べ、**酷暑でどれだけ／どう外れるか**を
原典の式から再現実装して比較したメモと、その検証スクリプト。

> ⚠️ **免責**: 本リポジトリのモデル実装は、各機関が公開している *考え方・補正ルール* を
> 原典記述から再現した **教材用の近似** です。収穫しきい値・RUE 値などの係数は
> 平年で現実的な収穫日になるよう本スクリプト側で較正したもので、各機関の正式パラメータ
> ではありません。目的は「酷暑下でモデル間の予測がどう割れるか」を数値で示すことです。

## 1. モデル4系統（調査まとめ）

| モデル | 開発・原典 | 予測の中身 | 主入力 | 公表精度 | 酷暑耐性 |
|---|---|---|---|---|---|
| 有効積算気温法 / 出荷期予測シート（**茨城 R4 法**） | 茨城県農業総合センター 令和2〜4年度成果 | 有効積算気温(5〜30℃)と個体重の正相関で収穫日を逆算＋中間補正 | 日平均気温(＋日射で補正) | 中間補正2段階で**実収穫日との誤差±4日以内** | ◎ 明示的な高温/低日射の減算式を持つ |
| 葉齢増加モデル / 結球重増加モデル | 農研機構 naroj 2019・野菜茶業研 2015。アプリ「キャベツ生育予測【メッシュ版】」 | 結球部生体重の日増加量＝日平均気温の関数、RUE も気温の関数。推定結球葉数から収穫開始日 | メッシュ農業気象データ(日平均気温) | 産地リレー出荷で実用 | ○ 気温関数に RUE 低減を内包 |
| **NARO 生育・収量予測ツール③ キャベツ** (`yieldpredict-cabbage`) | 農研機構／WAGRI、JFC技術の窓2701 | **日射量×気温で日々の重量増加をシミュレート**（受光量・RUE ベースの乾物生産型） | 日別 日射量・気温、品種、栽植密度、初期重量(or 1〜2か月時点の葉面積) | 葉面積入力時、**球重の誤差 平均±4.6%** | ○ 日射主入力で梅雨曇天を捉えやすい |
| 花芽分化予測モデル | 農研機構（温暖化影響評価 第2報） | 日平均気温で低温感応を積算し抽だい時期を予測 | 日平均気温 | 温暖化で抽だい前進を評価 | （高温より春の昇温・とう立ち側） |

参考: 国際標準の GDD 法でもアブラナ科は基準温度 3〜5℃・上限 24〜30℃、結球適温 15〜21℃で、
日本のモデルの「5〜30℃」と整合（ScienceDirect レビュー）。

## 2. 茨城 R4 予測法の補正（原典の式）

R3 法に次の補正を**追加**して酷暑年の過大予測を抑える:

1. **6〜8月の低日射補正**: 日積算日射量 H が定植時期別の閾値（回帰直線の傾き）を下回るとき、
   有効温度 T から `x = T − {(H·n)/A}·(A−B*)` を減算（梅雨・曇天で玉が太らない分）。
2. **7〜8月の高温補正**: 日有効温度 T のうち **25℃を超える分を減算**。
3. **1〜2月の低温補正**: 日有効温度が 10〜5℃のとき **×0.8** に減衰。

中間補正は実測2回：定植後 **20〜40日に「株の最大径」**、**55〜60日に「結球径」** を測定。
対応品種は **初恋・おきなSP・ふゆいろ**（2作型）。

> R3 法 vs R4 法の「平均誤差○日対○日」の対照統計表は、茨城県の成果 PDF/県報告書冊子の
> 図表内にのみ存在し、二次情報には転記されていない（未取得）。確定には県農業総合センターへの
> 原報請求が必要。

## 3. NARO 生育・収量予測ツール③ API 仕様（`yieldpredict-cabbage`）

| 項目 | 内容（WAGRI 公式） |
|---|---|
| 認証 | WAGRI 会員→`client_id`/`client_secret`→Token API で `grant_type=client_credentials`→アクセストークン |
| 予測 EP | `POST https://api.wagri2.net/naro-nivfs/prediction/v1/vegetable_yield` |
| 振り分け | リクエストの `品目` パラメータで作物別モデルへルーティング |
| リクエスト | JSON：栽培条件（品種・栽植密度・初期重量/葉面積・定植日）＋気象（日別 日射量・気温） |
| レスポンス | JSON：日別の個体重・収穫部重(球重)・収穫日 |
| 詳細パラメータ名 | 非公開（契約後配布の「API 利用手順書」に記載） |

呼び出し雛形（認証情報入手後にそのまま実行可）:

```bash
TOKEN=$(curl -s -X POST https://api.wagri.net/Token \
  -H "Content-Type: application/json" \
  -d '{"grant_type":"client_credentials","client_id":"'"$CID"'","client_secret":"'"$CSEC"'"}' \
  | jq -r .accessToken)

curl -s -X POST https://api.wagri2.net/naro-nivfs/prediction/v1/vegetable_yield \
  -H "X-Authorization: $TOKEN" -H "Content-Type: application/json" \
  -d '{"品目":"キャベツ","品種":"...","栽植密度":...,"初期重量":...,"定植日":"YYYY-MM-DD",
       "気象":[{"日付":"...","気温":..,"日射量":..}, ...]}'
```

> 実呼び出しには **有料 WAGRI 会員登録＋農研機構(野菜花き研)との API 利用契約** が必要。

## 4. シミュレーション結果（酷暑 vs 平年）

6/1 定植（結球肥大が盛夏に重なる作型）。平年で「上限 GDD・RUE 型」が +70 日に一致するよう較正し、
同じモデルを猛暑シナリオ（7-8月 +5℃、梅雨の日射 −35%）に通した収穫日予測：

| モデル | 平年 収穫 | 猛暑 収穫 | 猛暑のズレ |
|---|---|---|---|
| 素の GDD（上限なし） | 08/10 (+70日) | 08/01 (+61日) | **−9日** |
| 上限キャップ GDD(30℃) | 08/10 (+70日) | 08/02 (+62日) | −8日 |
| 茨城 R4 法（高温/低日射補正） | 08/12 (+72日) | 08/18 (+78日) | **+6日** |
| RUE 型（NARO 露地ツール相当） | 08/10 (+70日) | 09/10 (+101日) | +31日 |

**読み取り:**
- **素の GDD は猛暑で収穫を約9日前倒し** = 高温の熱量を生育に算入し過大評価。これが「気温は足りて
  いるのに玉が太らない」現場とのズレの正体。
- **茨城 R4 法は逆に +6日 遅らせる**方向に補正＝酷暑の停滞を織り込む。
- **RUE 型は梅雨低日射＋高温で大きく遅延**（日射主導で停滞を捉える）。ただし高温カットオフ(35℃で
  RUE=0)に敏感で、振れ幅は係数依存。
- いずれも 35℃級の生理障害（結球停止・芯腐れ・チップバーン）は構造的に外挿が苦手。
  2024年は実際に JA 豊橋で生育約2週間遅れ・産地リレー断絶・相場約3倍。
