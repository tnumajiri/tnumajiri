### 前年比・トレンド

- **FY2020（2021/3）**：巣ごもり・DIY 需要で営業利益+64.2%、純利益204億円で過去最高益。これがピーク。
- **FY2021〜FY2023**：園芸・農業・建築資材の反動減＋原材料高・円安で粗利率悪化。営業利益は4期連続で実質減少。
- **FY2023（2024/3）**：営業利益▲15.2%、純利益▲19.8% と大きく落ち込む。
- **FY2024（2025/3）**：増収増益に転じ下げ止まり（営業利益+1.4%、純利益+0.1%）。売上は3,700〜3,790億円台のレンジで頭打ち。

## 3. 企業概要

| 項目 | 内容 |
|---|---|
| 商号 | 株式会社コメリ（KOMERI CO., LTD.） |
| 証券コード | 8218（東証プライム・小売業） |
| 本社 | 新潟県新潟市南区清水4501-1 |
| 創業 / 設立 | 1952年4月（米穀店「コメリ商店」）/ 1962年7月 |
| 資本金 | 約188億円 |
| 事業 | ホームセンター事業を中核に、PB 商品開発、農業、リフォーム、Eコマース |
| 業態 | ハード＆グリーン（小型・郊外型）／コメリパワー（大型）／コメリPRO（プロ向け）／アテーナ（専門店） |
| 店舗数 | 約1,220店（2024/3末）→約1,227店（2025/9末）。全47都道府県展開 |

**ビジネスモデルの特徴**：米穀店ルーツを背景に**農業資材・園芸・建築資材に強い**地方郊外密着型 HC。小型「ハード＆グリーン」を高密度出店し、後から大型「パワー」を配置する"船団方式"でドミナント形成。PB 商品を企画〜製造〜販売まで自社展開。一方、農業・園芸・建築資材は天候・市況の影響を受けやすく、近年の業績変動要因にもなっている。
